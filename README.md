## Smart Contract

The NODA smart contract is based on OpenZeppelin ERC20.

The deployed contract has:

- Fixed supply
- No public mint function
- No owner or administrator
- No burn function
- No blacklist
- No pause function
- No transfer tax or fee
- No upgradeability

Source code is publicly verified on BscScan with Exact Match verification.
